How my reports look

Examples in the format I use for client work. Details are from public practice apps or made up for illustration.

BUG-003 · Checkout · problem_user

Last name field doesn't accept input at checkout

High severityPriority: High
Environment
Chrome (latest), Windows 11
Impact
Blocks checkout completely for affected users
Steps to reproduce
  1. Log in as problem_user and add any item to the cart.
  2. Open the cart and click Checkout.
  3. Type a first name, then type a last name.
  4. Click Continue.
Expected
Both names are saved and the overview page opens.
Actual
The last name doesn't keep its value and "Last Name is required" is shown.
API-BUG-002 · POST /booking

Missing required fields return 500 instead of 400

Medium severityReproduces 5/5
POST /booking
Content-Type: application/json

{ "firstname": "Test" }
Expected
400 Bad Request, with a message listing the missing fields.
Actual
500 Internal Server Error, with no details.

A simple validation mistake looks like a server crash, so the app can't tell users what to fix, and monitoring raises false alarms.
